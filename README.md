# VVebo 3.3.31 补丁测试包 v1.1

**初版综合测试包收到用户“启动即闪退”的反馈，已撤回当前下载链接。**

v1.1 修正补丁中 7 个系统基础类的动态库绑定，并对照原 IPA 的导入记录检查所有外部系统符号。没有取得崩溃日志，尚未确认这是否为此前闪退的唯一原因；v1.1 尚未经过真机启动验证。

## 建议先测试仅主页版本

- [下载仅主页修复 v1.1](downloads/VVebo-3.3.31-ProfileFix-v1.1.ipa)：不启用窗口布局改动，先验证启动和主页。
- [使用说明及手机查看崩溃记录的方法](downloads/使用说明-v1.1.txt)
- [补丁源码与构建/检查脚本](downloads/VVeboPatch-source-v1.1.zip)

[综合测试 v1.1（附窗口填充尝试）](downloads/VVebo-3.3.31-ProfileFix-SceneFill-v1.1-Test.ipa) 保留供后续排查；在仅主页版验证正常前，不建议安装。黑边效果尚未验证，若来自系统兼容显示模式，窗口填充可能无效。

IPA 文件页面点击 **Download raw file / 下载原始文件**。两个测试包使用相同 Bundle ID，择一安装，均需要支持当前系统的工具重新签名；临时 ad-hoc 签名不是普通 iOS 可直接安装的开发者签名。标准 TrollStore 不支持 iOS 26。

不要先删除原 App，以免丢失本地数据。测试时关闭 QX 中 VVebo 专用重写。若仍闪退，使用原 IPA 通过原安装方式恢复，并提供手机分析数据中的相关崩溃原因截图。

## 修改与验证范围

主页补丁参考用户提供并确认有效的 [bin64 QX 脚本](https://raw.githubusercontent.com/bin64/Scripts/main/QuantumultX/vvebo.js)：切换主页列表接口，转换翻页参数及返回卡片格式。在本地应用内处理，不引入额外代理服务器、不记录鉴权信息。

通过了 arm64 交叉编译、系统符号导入来源比对、ZIP、加载命令、依赖绑定、补丁启动入口、代码页/资源签名结构检查；保留原应用指令、身份和权限声明。QX 参考算法仅用合成数据验证。

Linux 云环境无法运行 UIKit 应用。没有完成真机启动、正式签名、在线接口、翻页或黑边验证。结构检查通过不证明修复成功。
